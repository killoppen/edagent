# 冻结评测集 frozen-v1

本评测集与黄金岗位包 1.0.0 同步冻结，用于判断后续自动生产工作流是否达到人工审视基准，而不是用于把候选内容全部过滤掉。

- `structural-assertions.json`：结构、唯一 ID、必要关系、孤立节点、证据绑定、事理要素和禁止关系。
- `semantic-cases.jsonl`：应合并、不应合并、类型分类和典型粒度错误。
- `evidence-cases.jsonl`：直接事实、跨来源归纳、研究推断、争议、拒绝、有限来源和时间版本案例。
- `agent-qa.jsonl`：岗位解释、相邻岗位、任务、过程、能力、学习、节点引用、证据追问和不足证据表达。

验证命令：

```bash
npx tsx scripts/validate-golden-role-package.ts
```

语义和 Agent 案例不是简单关键词评分模板。自动工作流评测应同时检查：关键事实覆盖、稳定 ID 引用、证据定位、断言状态、范围限定、禁止结论和答案是否把推断冒充来源原文。
